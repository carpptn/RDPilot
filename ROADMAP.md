# RDPilot Roadmap

This roadmap communicates direction rather than fixed commitments or dates.
Priorities may change as desktop-agent models, APIs, and real-world usage evolve.

## Current foundation

- Reliable observe, act, verify, and recover control loop
- Finite and continuous goals
- Mouse, keyboard, clipboard, gestures, and UI Automation actions
- Loop detection and persistent recovery memory
- File-based configuration through `appsettings.json`
- Deterministic self-tests and portable Windows releases

## Next

- Publish short, reproducible demo scenarios and recordings
- Improve first-run setup, diagnostics, and configuration guidance
- Expand deterministic evaluations for common Windows applications
- Add finer-grained application and action permissions
- Improve failure explanations and recovery-memory inspection
- Automate repeatable release packaging and integrity checks

## Later

- Extensible action and integration interfaces
- Additional model-provider options
- Richer accessibility and UI Automation strategies
- A visual run and replay inspector
- Signed binaries and a smoother Windows installation experience

Ideas and focused proposals are welcome through GitHub issues. Safety,
reproducibility, and measurable reliability take priority over feature count.
